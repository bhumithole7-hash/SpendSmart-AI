# SpendSmart AI 💰

SpendSmart AI is a personal expense management web application designed to help users track their expenses, organize spending, and understand their financial habits through a simple dashboard.

## 🚀 Features

- Add and manage daily expenses
- Categorize expenses
- Track total spending
- View spending summaries
- User-friendly dashboard
- React-based frontend
- Python backend
- SQLite database for storing data

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Python
- Flask

### Database
- SQLite
